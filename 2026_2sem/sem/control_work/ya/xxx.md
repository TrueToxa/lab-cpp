В олимпиаде по ОБЖ участвовало K учеников 10-го класса. После подведения итогов олимпиады решили разделить участников на M групп по N учеников (K = MN). Цель разделения проста: уменьшить разброс в оценках учеников внутри каждой группы.

В качестве ответа требуется вывести максимальную разность между высшим и низшим результатами в группе из N учеников по всем группам. Дополнительно требуется вывести среднее значение минимальной разности внутри группы по M группам.

Формат ввода
Вначале передается количество учеников K, затем следует количество групп M, потом следует количество учеников в группе N.

После следует K чисел -- оценки учеников за олимпиаду.

Формат вывода
Вывести два числа:

максимальную минимальную разность между оценками в группе
среднее значение минимальной разности, усредненное по группам
